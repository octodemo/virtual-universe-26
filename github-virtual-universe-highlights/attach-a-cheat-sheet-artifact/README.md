**Final exercise · 5 min · 3 steps**

You're almost done with the workshop! To bring everything you learned together
you will create an Issue Artifact.

> **Issue Artifacts** let you attach rich, structured artifacts; implementation
> plans, research and investigation notes, design docs, images and reference
> links — directly to a GitHub issue. Instead of important context living in
> scattered comments or external tools.

In this section you'll use the `/create-issue-artifact` skill to attach a
cheat sheet of the top updates from the Virtual Universe practical sessions to
an issue.

[![Open in Copilot App](https://img.shields.io/badge/Open_in_Copilot_App-238636?style=flat&logo=githubcopilot&logoColor=white)](https://github.com/copilot/app/launch?open=ghapp%3A%2F%2Fsession%2Fnew%3Frepo%3Doctodemo%252Fvirtual-universe-26%26canvas%3Duniverse-cheatsheet-artifact)

The link opens a session with this guide as a canvas. Already in a session? Open
**+ → Installed extensions → Universe '26 cheat sheet artifact**.

## 1. Create your issue

In the guide canvas, press **Create my issue**.

The canvas finds your fork of `octodemo/virtual-universe-26` (or creates one if
you don't have it yet), turns on issues, opens the issue there, and then opens a
session already linked to it. You don't need your fork checked out locally, and
no Copilot turn is involved.

Not using the canvas? Ask Copilot instead:

```text
Create an issue titled "My GitHub Universe '26 cheat sheet" in my fork and open a session for it
```

Switch to the new session since `/create-issue-artifact` attaches to the issue
linked to the session you run it in. This guide opens there too.

## 2. Run the skill

```text
/create-issue-artifact follow github-virtual-universe-highlights/attach-a-cheat-sheet-artifact/instructions.md
```

Copilot reads [the instructions](instructions.md), then, in about a minute:

- opens the **Badge Simulator** with a surprise on your badge, which starts
  recording straight away
- adds the **GitHub Universe 2026 cheat sheet** to your issue as an artifact
- adds a second artifact, **How Copilot built this**, with its working notes
  from the session

## 3. Watch your badge record itself

As soon as the Badge Simulator opens it records your badge for a few seconds
and adds it to your issue as a third artifact, **Your Virtual Universe 26
badge** — no extra Copilot step. Keep the panel in front while it records.

Open the issue and select **Artifacts** to see it. Want the GIF on your
machine? Press **Share** in the simulator and it lands in your Downloads
folder as `virtual-universe-26-badge.gif`, ready to post anywhere. Want to
keep playing? Try the [online badge simulator](https://badger.github.io/simulator/).
