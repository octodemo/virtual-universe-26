# Universe Congrats

Astronaut Mona celebrates you finishing the GitHub Virtual Universe '26 tutorials.

## Usage

Open the app to see the celebration. It greets the learner by `@login`, which
the Badge Simulator canvas provides in `github_login.txt`, and shows
"Well done!" when that file is missing (for example on a real badge). The name
is drawn from Mona Sans glyph atlases (`assets/glyphs.png` and
`assets/glyphs_small.png` for long logins), made with `badge-glyphs.html` and
`badge-png.py` in
`github-virtual-universe-highlights/attach-a-cheat-sheet-artifact/`. No extra
hardware or network access is required.

Astronaut Mona (purple eyes) was made with [My Octocat](https://myoctocat.com/build-your-octocat/).
